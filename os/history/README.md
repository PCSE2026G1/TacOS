# 再生履歴

## 機能

- 再生開始に成功した曲のパスをPLAYHIST.TXTへ記録する．
- 同じ曲をまとめ，ファイル名と再生回数を表示する．
- 英字の大文字・小文字を区別せず集計する．
- 表示順は最初に履歴へ登場した順とする．
- ボタン1・5で上下移動し，ボタン4で呼出し元へ戻る．

## 公開関数

- recordPlayHistory(file)：履歴を記録し，成功ならtrueを返す．
- showHistory()：PLAYHIST.TXTを集計して表示する．

AudioDecoderのMP3playfile(file, true)が再生開始に成功した場合に記録する．
false指定・再生開始失敗時には記録しない．
履歴保存に失敗しても，再生開始に成功していればMP3playfileはtrueを返す．
保存失敗はログへ出力する．

## 保存形式と制限

- 保存先は/PLAYHIST.TXT．1行につき1回の再生パスを記録する．
- ファイルがない場合は記録時に新規作成する．
- パスは最大255文字．改行コードはLF．
- NUL・CR入りの履歴はエラーとして扱い，勝手に削除・修復しない．
- 記録時は既存履歴を読み込み，全体を書き戻す．
- バッファサイズの計算を32767バイト以下に制限する．
- 実際には空きメモリ量により，それより小さい履歴でも確保に失敗し得る．
- 保存中の障害・電源断に対する原子的更新は未対応．
- 同じ履歴ファイルへの複数プロセスからの同時更新は未対応．
- 画面は開いた時点の集計結果を表示する．
- 旧/playHistory.txtからの自動移行は行わない．

## 専用テスト

TaC用ツールチェーン，CMake，Ninja，C/C++コンパイラを必要とする．
リポジトリ直下で実行する．

```sh
make -C os/history/tests test-kernel
size-- os/history/tests/build/kernel0.o
```

共有部品はcommit済みソースを/private/tmpへ展開してビルドする．
HistoryとAudioDecoderは現在の作業ファイルを使用する．
元の共有Home・CMakeLists.txtは変更しない．

生成物はos/history/tests/build/kernel0.bin．
本番のos/kernel0.binと取り違えないこと．

## 確認済み

- 記録ファイルの新規作成・複数回の記録
- 不正入力の拒否と既存内容の保持
- パスのコピー・集計・大文字小文字の同一視
- ファイルなし・空ファイル・末尾改行なしの読込み
- 64バイト境界と255文字の読込み
- 不正データ検出時に部分的な集計結果を返さないこと
- 曲名・回数表示，上下移動，ページ切替，呼出し元への復帰
- 空履歴・読込み失敗画面からの復帰
- save=trueで回数が増え，save=falseでは増えないこと
- RESET後の履歴保持

一時コピーの本番Homeへ接続した構成でも，
Home→History→Home，Filesからの再生後の回数増加を実機確認した．
この接続例には，PlaylistのPRで提出したMP3Player・ClockViewerの変更も使用した．

## 本番接続

- Historyモジュールを組込みカーネルのビルド対象へ登録する．
- HomeのHistory項目からshowHistory()を呼ぶ．
- C側から呼ぶ場合は既存のC/C--間の宣言形式へ合わせる．
- Homeのスタック設定は担当者と調整する．

AudioDecoderがHistoryへ依存するため，モジュール登録は必須．
Homeへの接続だけでなく，ビルド登録も合わせて反映すること．
共有ファイルの接続差分は，部品単体の変更とは分けて担当者と調整する．

## 統合版のエラー通知

本番カーネルの小型化のため，長いエラー文を次の識別コードへ短縮した．
入力検証，失敗時の解放，部分的な集計結果の破棄は残している．
エラー通知はDEBUGの有無によらず出力する．

| コード | 意味 |
| --- | --- |
| H01 | 集計情報の確保失敗 |
| H02 | 集計対象のパスに改行を含む |
| H03 | 集計対象のパス長が不正 |
| H04 | 再生回数の上限超過 |
| H05 | 曲の種類数の上限超過 |
| H06 | 曲エントリの確保失敗 |
| H07 | 曲パスの確保失敗 |
| H08 | 記録関数の引数がnull |
| H09 | 記録対象のパスに改行を含む |
| H10 | 記録対象のパス長が不正 |
| H11 | Stat情報の確保失敗 |
| H12 | 記録先が不適切，またはstat失敗 |
| H13 | 履歴サイズが上限を超える |
| H14 | 記録バッファの確保失敗 |
| H15 | 既存履歴のopen失敗 |
| H16 | 既存履歴の読取り・close失敗 |
| H17 | 既存履歴にNUL・CRなどの非対応文字 |
| H18 | 履歴ファイルの作成失敗 |
| H19 | 書込み用open失敗 |
| H20 | 書込み・close失敗 |
| H21 | 読込み元のファイル名が不正 |
| H22 | 履歴読込み用open失敗（ファイルなしは空として扱う） |
| H23 | 読込みバッファの確保失敗 |
| H24 | 読込み後のclose失敗 |
| H25 | read失敗 |
| H26 | 読込み中にNUL・CRなどの非対応文字 |
| H27 | 読込み中のパスが255文字を超える |

小型化しても，保存中の電源断や同時更新への制限は変わらない．
